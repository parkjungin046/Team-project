# 관리자 페이지 사용법

이 폴더는 **본인 컴퓨터에서만 실행되는 로컬 전용 관리자 페이지**입니다. 외부 서버에 배포되지 않으며, 다른 사람은 접속할 수 없습니다.

## 처음 한 번만: 설치

```bash
npm install
```

## 관리자 비밀번호 설정 / 변경

```bash
npm run set-admin-password -- "원하는비밀번호"
```

- 입력한 비밀번호는 어떤 파일에도 평문으로 남지 않습니다.
- `bcrypt`로 되돌릴 수 없게 암호화된 값만 `.env` 파일에 저장됩니다.
- `.env`는 `.gitignore`에 등록되어 있어 GitHub에는 절대 올라가지 않습니다.

## 실행

```bash
npm run admin
```

터미널에 아래처럼 뜨면 정상 실행된 것입니다.

```
✅ 관리자 페이지가 실행되었습니다: http://localhost:4300
```

브라우저에서 `http://localhost:4300` 접속 → 비밀번호 입력 → 프로젝트 등록/수정.

## 프로젝트 등록 → 웹사이트 반영까지

1. 관리자 페이지에서 프로젝트 정보를 입력하고 "공개"를 선택해 저장합니다.
2. 저장 즉시 `data/public-projects.generated.js` 파일이 자동으로 갱신됩니다.
   - 로컬에서 `npx serve .` 등으로 사이트를 보고 있다면 새로고침만으로 바로 확인됩니다.
3. 실제 배포 사이트(GitHub 등)에 반영하려면, 평소처럼 변경 사항을 커밋 & 푸시하면 됩니다.
   ```bash
   git add data/public-projects.generated.js
   git commit -m "프로젝트 추가"
   git push
   ```
4. "초안"으로 저장한 프로젝트는 이 파일에 포함되지 않으므로 실제 웹사이트에는 절대 노출되지 않고,
   관리자 페이지에만 계속 남아 있습니다 (다시 로그인해도 그대로 유지됩니다).

## 보안 설계 요약

- 비밀번호는 bcrypt 해시로만 `.env`에 저장되고, 프론트엔드로 전송되지 않습니다.
- `.env`, `data/projects.json`(초안 포함 원본)은 `.gitignore`로 GitHub 업로드에서 제외됩니다.
- 로그인 세션은 `httpOnly` 세션 쿠키로만 유지되며, **만료 시간을 지정하지 않아** 브라우저를 완전히 닫으면
  자동으로 삭제됩니다 → 다시 열면 항상 새로 로그인해야 합니다.
- 관리자 서버를 재시작할 때마다 세션 암호화 키가 새로 생성되어, 이전 세션은 모두 즉시 무효화됩니다.
- 로그인 실패가 10분 내 5회를 넘으면 일시적으로 잠깁니다.
- 서버는 `127.0.0.1`(로컬)에만 열리며, 같은 네트워크의 다른 기기에서도 접속할 수 없습니다.

## 중복 프로젝트 정리

제목이 같은(공백 차이만 있어도 인식) 프로젝트가 2건 이상이면 관리자 페이지 상단에 경고가 표시됩니다.
남기고 싶은 항목의 "이것만 남기기" 버튼을 누르면 나머지는 삭제되고 하나로 통합됩니다.
